# Lab 5 – Decision Tree Classifier and Model Evaluation[cite: 1]

## Objective

The objective of this lab is to build, train, and evaluate a Decision Tree classifier using machine learning libraries, and to assess its performance using various metrics[cite: 1].

---

## Experiments

### 1. Decision Tree Classifier

#### Problem Statement

Train a Decision Tree classification model on a dataset to predict categorical target labels based on input features[cite: 1].

#### Approach

* Preprocess and split the dataset into training and testing sets.
* Train a Decision Tree model using splitting criteria like Gini impurity or Information Gain (Entropy).
* Visualize the trained decision tree structure to interpret the split decisions.

#### Learning Outcome

Understands how tree-based models recursively partition data and make transparent, rule-based classification decisions[cite: 1].

---

### 2. Model Evaluation

#### Problem Statement

Evaluate the performance of the classification model using comprehensive metrics and visualization tools[cite: 1].

#### Analysis Approach

* Generate a **Confusion Matrix** to analyze true positives, true negatives, false positives, and false negatives.
* Compute performance metrics including **Accuracy, Precision, Recall, and F1-Score**.

#### Learning Outcome

Mastered the evaluation techniques required to measure classification model effectiveness and diagnose performance trade-offs[cite: 1].
