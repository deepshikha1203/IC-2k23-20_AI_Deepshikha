## Experiments

### 1. Explainable AI (Grad-CAM) and Adversarial AI (FGSM)

#### Problem Statement

Implement interpretability and robustness techniques to understand model decisions and test vulnerability against adversarial perturbations[cite: 1].

#### Approach

* **Grad-CAM (Gradient-weighted Class Activation Mapping):** Generate visual heatmaps highlighting the regions of an image that contributed most to a convolutional neural network's decision.
* **FGSM (Fast Gradient Sign Method):** Generate adversarial examples by adding small, targeted perturbations to input data using gradients to fool the model.

#### Learning Outcome

Understands how to inspect black-box model predictions for transparency and analyze model vulnerability against adversarial attacks[cite: 1].

#### Problem Statement

Apply dimensionality reduction techniques to high-dimensional data and integrate concepts into an end-to-end mini project[cite: 1].
