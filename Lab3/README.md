## Objective

The objective of this lab is to learn data manipulation, exploratory data analysis (EDA), and visualization techniques using Python libraries like NumPy and Pandas[cite: 1].

## Experiments

### 1. NumPy and Pandas Fundamentals

#### Problem Statement

Perform array operations and manage tabular datasets using vectorized operations and dataframes.

#### Operations

* Loading datasets using Pandas (`pd.read_csv()`)[cite: 1].
* Inspecting data structure, handling missing values, and cleaning rows/columns.
* Performing matrix and statistical operations using NumPy.

#### Learning Outcome

Gains proficiency in efficient data handling and preprocessing raw data for downstream tasks[cite: 1].

### 2. Exploratory Data Analysis (EDA) and Visualization

#### Problem Statement

Analyze patterns, correlations, and distributions within a dataset using statistical summaries and graphical plots[cite: 2].

#### Analysis Approach

* Compute descriptive statistics (mean, median, variance, correlation matrices).
* Generate visual representations using visualization libraries (histograms, box plots, scatter plots, and heatmaps)[cite: 2].
