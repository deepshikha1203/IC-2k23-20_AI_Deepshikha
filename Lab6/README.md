# Lab 6 – PyTorch Basics, Linear Regression, and Neural Network Fundamentals[cite: 1]

## Objective

The objective of this lab is to introduce PyTorch basics, implement linear regression, and understand the fundamental concepts of building and training neural networks[cite: 1].

---

## Experiments

### 1. PyTorch Basics and Linear Regression

#### Problem Statement

Implement tensor operations in PyTorch and build a simple linear regression model to fit a line to a given set of data points[cite: 1].

#### Approach

* Create and manipulate tensors, perform automatic differentiation using `torch.autograd`.
* Define a linear regression model using PyTorch modules, loss functions (e.g., Mean Squared Error), and optimizers (e.g., SGD).
* Train the model iteratively using forward passes, loss computation, backpropagation, and weight updates.

#### Learning Outcome

Understands tensor manipulation, gradient computation, and the basic training loop mechanics in deep learning frameworks[cite: 1].

---

### 2. Neural Network Fundamentals

#### Problem Statement

Build a basic feedforward neural network using PyTorch to solve a classification or regression problem[cite: 1].

#### Approach

* Construct a multi-layer perceptron (MLP) using `nn.Module`, incorporating hidden layers and activation functions (e.g., ReLU, Sigmoid).
* Train the neural network on a dataset and evaluate its performance across multiple epochs.

#### Learning Outcome

Gained hands-on experience in defining network architectures, understanding non-linear activation functions, and training foundational neural networks[cite: 1].
