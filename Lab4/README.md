# Lab 4 – Knowledge Representation, Rule-Based Systems, and Semantic Networks[cite: 1]

## Objective

The objective of this lab is to explore knowledge representation techniques, implement rule-based expert systems, and construct semantic networks to model relationships[cite: 1].

---

## Experiments

### 1. Rule-Based Systems

#### Problem Statement

Implement a rule-based inference system that uses IF-THEN rules to derive conclusions or make decisions based on a given set of facts[cite: 1].

#### Approach

* Define a knowledge base containing facts and production rules.
* Implement a forward-chaining or backward-chaining inference engine to evaluate rules and deduce new information.

#### Learning Outcome

Understands how expert systems represent human expertise using structured rules and logical inference mechanisms[cite: 1].

---

### 2. Semantic Networks

#### Problem Statement

Construct a semantic network graph to represent knowledge using nodes (objects, concepts, or situations) and labeled edges (relations)[cite: 1].

#### Approach

* Model hierarchical relationships such as "is-a" (inheritance) and "has-a" (aggregation).
* Traverse the network structure to query properties and inherit attributes across connected concepts.

#### Learning Outcome

Demonstrates how graph-based knowledge representation enables structured storage, inheritance, and relational querying[cite: 1].
